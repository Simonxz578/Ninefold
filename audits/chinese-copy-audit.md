## 审计范围与结论

本审计以当前实现为准，主要来源包括：

- `src/i18n/zh-CN.ts`：简体中文主词典；
- `src/i18n/types.ts`：中英文键值结构约束；
- `src/domain/reflectionLocale.ts`：独立编写的中文回望模板；
- `src/pages/`：页面标题与主要操作；
- `src/components/landscape/RestMode.tsx`：停留模式内部文案；
- `src/components/landscape/LivingLandscape.tsx`：非视觉风景说明；
- `src/pages/ArchivePage.tsx`：中文一周小结；
- `src/App.tsx`：中文安全分享文案。

当前中文基线整体自然、克制、可理解，没有使用命运论、占卜式暗示或企业化空话。主产品名、九条心径、五种照料动作及核心体验阶段均与锁定术语一致。

**自动测试只能验证键值、确定性与渲染约束，不能证明文学质量。正式公开前仍需由母语编辑进行最终人工审读。** 本文末尾列出需要人工确认或继续修正的项目。

## 错误、空状态与恢复信息

### 输入与操作

- 心径未选：`请选择一条心径后继续。`
- 今日感知未完成：`请完成精力、清晰度、联结与关注选项后继续。`
- 照料动作未选：`请选择一个照料动作，让今天的风景继续生长。`
- 通用失败：`刚才的操作没有完成，请再试一次。`
- 印记不可用：`暂时无法取得所选印记。`

### 本地存储与迁移

- 不可用：`浏览器本地存储当前不可用。本次体验仍可继续，但刷新后风景可能无法保留。`
- 无效或旧版数据：`一项无效或旧版的九境生息数据已被安全忽略，其余体验仍可继续。`
- 读取失败：`部分本地数据无法读取，九境生息正在使用安全的备用值。`
- 写入失败：`浏览器本地存储暂时无法更新，本次会话仍可继续。`
- 迁移完成：`你此前的 Ninefold 个人资料与历史，现已进入这片生长风景。`
- 迁移未完整完成：`部分旧数据无法迁移，原有本地值没有被改动。`
- 清除完成：`九境生息数据已从这个浏览器中清除。`

### 下载、分享与反馈

- 每日 SVG 失败：`SVG 暂时无法下载，请再试一次。`
- 七日 SVG 失败：`七日 SVG 暂时无法下载，请再试一次。`
- 自动复制不可用：`当前浏览器无法自动复制，请在下方选中文案后复制。`
- 反馈无法保存：`本次会话中仍可看到反馈，但暂时无法保存。`

### 路由与渲染恢复

- Not Found 标记：`没有找到这条路径`
- Not Found 标题：`这条路没有通向你的风景。`
- Not Found 说明：`地址可能不完整，或对应页面已经不可用。`
- Error Boundary 标题：`这片风景暂时无法显示。`
- Error Boundary 说明：`已保存的本地数据没有被清除。请刷新页面后再试。`
- 恢复操作：`返回首页`

## 自动化保障

当前实现具备以下自动化或类型层保障：

- `en.ts` 与 `zh-CN.ts` 同时满足 `TranslationDictionary`，避免缺失键静默进入构建；
- 字典测试检查键值一致性、锁定术语与禁止变体；
- 路由测试检查 `#/en/...` 与 `#/zh/...` 映射；
- 日期测试检查中文 `Intl.DateTimeFormat` 输出；
- Provider 测试检查 `document.documentElement.lang` 与语言切换；
- Domain 测试检查切换语言不会改变配置，并检查中文回望的确定性；
- 组件使用翻译后的可见文字与主要 ARIA 标签。
